# Credit_Card_Financial_Dashboard
Interactive dashboard to visualize and analyze credit card customer data. Includes KPIs, customer segmentation, quarterly trends, and expenditure patterns. Built using Power BI for data-driven insights.

Credit Card Customer Analytics – Power BI
Overview
Credit Card Customer Analytics is an interactive Power BI dashboard project for analyzing customer data, revenue, and transaction patterns in the credit card business.

Features
KPI Cards: Instant stats for revenue, income, interest earned, and customer satisfaction.

Segmentation: Insights by card type, job, education, income level, gender, and state.

Trends & Visualization: Quarterly, demographic, and expenditure breakdowns.

Filters & Slicers: Easy drilldowns based on quarter, gender, income group, and more.
